# Assets

Recursos estaticos de la aplicacion.

## Estructura
- assets/fonts/: fuentes tipograficas
- assets/images/: imagenes generales
- assets/illustrations/: ilustraciones de interfaz o curso
- assets/icons/: iconos web/app (no Android nativo)
- assets/favicon/: favicon del sitio
- assets/android/icons/: iconos Android para la etapa de Capacitor
- assets/ios/icons/: iconos iOS para la etapa de Capacitor
- assets/ios/splash/: splash iOS para la etapa de Capacitor
