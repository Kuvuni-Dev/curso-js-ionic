# Assets

## ES-EN

| Sección | Español | English |
|---|---|---|
| Qué hace | Esta carpeta centraliza todos los recursos visuales y estáticos de la aplicación. | This folder centralizes all visual and static resources used by the application. |
| Para qué sirve | Separar assets del código fuente para facilitar mantenimiento, reemplazo y empaquetado. | Keeps assets separated from source code for easier maintenance, replacement, and packaging. |

## Estructura / Structure

| Ruta / Path | Español | English |
|---|---|---|
| assets/fonts/ | Fuentes tipográficas del proyecto. | Project typography files. |
| assets/images/ | Imágenes generales de apoyo visual. | General support images. |
| assets/illustrations/ | Ilustraciones para UI o contenidos del curso. | Illustrations for UI or course content. |
| assets/icons/ | Iconos para web/app (no nativos Android). | Icons for web/app usage (not native Android icons). |
| assets/favicon/ | Favicons del sitio web. | Website favicons. |
| assets/android/icons/ | Recursos de iconos Android para etapa Capacitor. | Android icon resources for Capacitor stage. |
| assets/ios/icons/ | Recursos de iconos iOS para etapa Capacitor. | iOS icon resources for Capacitor stage. |
| assets/ios/splash/ | Pantallas splash para iOS en etapa Capacitor. | iOS splash screens for Capacitor stage. |
