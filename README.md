# Curso JS Avanzado + Ionic (Vanilla)

Estructura inicial para una app didactica dividida en:
- Bloque JavaScript avanzado
- Bloque Ionic (componentes)
- Lectura de contenidos Markdown dentro de la app
- Preparacion para despliegue web y Android con Capacitor

## Estructura

- src/: codigo de la aplicacion
- content/md/: archivos Markdown del curso
- docs/: guias de arquitectura y roadmap
- index.html: entrada de la app para Live Server

## Siguiente paso

Abrir index.html con Live Server y continuar con el desarrollo de modulos (JS, Ionic y Markdown).

## Ejecucion

1. Instala la extension Live Server en VS Code.
2. Haz click derecho en index.html y selecciona "Open with Live Server".
3. Navega por las rutas desde la barra superior de la app.
