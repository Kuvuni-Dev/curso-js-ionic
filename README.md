# Curso JS + Ionic

## README bilingüe (ES/EN)

| Sección | Español | English |
|---|---|---|
| Descripción | Esta aplicación es una plataforma de aprendizaje interactiva para enseñar JavaScript e Ionic. Combina teoría en Markdown con demos ejecutables para leer, practicar y comparar resultados en un solo flujo. | This application is an interactive learning platform to teach JavaScript and Ionic. It combines Markdown theory with executable demos so learners can read, practice, and compare results in one workflow. |
| Qué hace | Presenta contenidos navegables, demos de JavaScript (básico/avanzado), demos de componentes Ionic, y carga material Markdown del curso. También está preparada para evolucionar a despliegue web y empaquetado móvil con Capacitor. | It provides navigable course content, JavaScript demos (basic/advanced), Ionic component demos, and Markdown course material. It is also ready to evolve toward web deployment and mobile packaging with Capacitor. |
| Público objetivo | Estudiantes que refuerzan JavaScript con práctica guiada, alumnos de Ionic que necesitan ejemplos reales y profesores que requieren una base reutilizable para cursos de 20-30 horas. | Students reinforcing JavaScript with guided practice, Ionic learners needing real examples, and instructors requiring a reusable base for 20-30 hour courses. |

## Estructura / Structure

| Ruta / Path | Español | English |
|---|---|---|
| src/ | Código principal de la app (app, router, módulos y vistas). | Main app code (app, router, modules, and views). |
| src/modules/js/ | Demos y vistas del bloque JavaScript. | Demos and views for the JavaScript block. |
| src/modules/ionic/ | Demos y vistas del bloque Ionic. | Demos and views for the Ionic block. |
| content/md/ | Contenidos Markdown del curso. | Course Markdown content. |
| docs/ | Arquitectura, roadmap y documentación interna. | Architecture, roadmap, and internal documentation. |
| assets/ | Fuentes, imágenes, iconos y recursos visuales. | Fonts, images, icons, and visual assets. |
| index.html | Punto de entrada para ejecución local con Live Server. | Entry point for local execution with Live Server. |

## Flujo de uso / Usage flow

| Paso | Español | English |
|---|---|---|
| 1 | El alumno selecciona un bloque (JS o Ionic). | The learner selects a block (JS or Ionic). |
| 2 | Lee la explicación del tema. | Reads the topic explanation. |
| 3 | Ejecuta una demo interactiva. | Runs an interactive demo. |
| 4 | Observa la salida, compara casos y resuelve mini-retos. | Reviews output, compares scenarios, and solves mini-challenges. |

## Ejecución local / Local run

| Paso | Español | English |
|---|---|---|
| 1 | Instala la extensión Live Server en VS Code. | Install the Live Server extension in VS Code. |
| 2 | Abre index.html con Open with Live Server. | Open index.html with Open with Live Server. |
| 3 | Navega por la barra superior para cambiar entre bloques y demos. | Use the top navigation bar to switch between blocks and demos. |

## Objetivo pedagógico / Pedagogical goal

- ES: Reducir la distancia entre teoría y práctica: cada concepto debe poder leerse, ejecutarse y validarse rápidamente dentro de la misma app.
- EN: Reduce the gap between theory and practice: every concept should be readable, executable, and quickly validated inside the same app.
