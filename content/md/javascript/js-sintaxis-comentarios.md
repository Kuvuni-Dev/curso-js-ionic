# Sintaxis y comentarios

La sintaxis son las reglas para escribir código válido.

## Instrucciones y punto y coma

```js
const nombre = 'Lucía';
console.log(nombre);
```

El punto y coma es opcional en muchos casos, pero mantenerlo mejora la consistencia.

## Sensibilidad a mayúsculas

JavaScript distingue entre mayúsculas y minúsculas.

```js
const usuario = 'Ana';
// usuario y Usuario NO son lo mismo
```

## Comentarios

```js
// Comentario de una línea

/*
  Comentario
  de varias líneas
*/
```

## Nombres de variables

- Usa nombres claros: `totalCompra`, `edadAlumno`.
- Evita nombres genéricos como `x` o `dato` salvo en ejemplos cortos.
