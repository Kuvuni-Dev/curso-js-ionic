# Introducción a JavaScript y ejecución

JavaScript es el lenguaje que da comportamiento a las páginas web.

## Dónde se ejecuta JavaScript

- En el navegador (cliente).
- En servidores con Node.js.

## Incluir JavaScript en HTML

```html
<script src="app.js"></script>
```

También se puede escribir dentro de una etiqueta `script`.

```html
<script>
  console.log('Hola JavaScript');
</script>
```

## Primer programa

```js
console.log('Hola, mundo');
```

## Recomendación para empezar

1. Escribe ejemplos pequeños.
2. Ejecuta en consola del navegador.
3. Revisa errores en DevTools.
