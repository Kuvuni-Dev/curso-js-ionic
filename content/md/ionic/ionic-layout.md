# Layout y contenido en Ionic

Ionic tiene componentes para organizar el contenido en pantallas limpias y responsive.

## Listas y cards

- `ion-list` y `ion-item`: listados estándar.
- `ion-card`: tarjetas visuales con cabecera, contenido y botones.

## Grid

`ion-grid` usa `ion-row` e `ion-col` para diseños responsivos.

```html
<ion-grid>
  <ion-row>
    <ion-col size="6">Columna 1</ion-col>
    <ion-col size="6">Columna 2</ion-col>
  </ion-row>
</ion-grid>
```

## Componentes de presentación

- `ion-badge`: indicador pequeño.
- `ion-chip`: etiqueta compacta.
- `ion-avatar`: imagen de perfil.
- `ion-icon`: iconos vectoriales.

## Overlays de contenido

`ion-accordion` crea secciones expandibles para mostrar/ocultar información.
