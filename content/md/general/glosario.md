# Glosario del curso

Definiciones rápidas de términos clave. Ideal para repaso durante el estudio.

## A

**Async/Await**: Sintaxis moderna para trabajar con promesas. `async` marca una función que devuelve promesa, `await` pausa su ejecución hasta que la promesa se resuelva.

**Arrow function**: Función con sintaxis acortada usando `=>`. Hereda `this` del contexto envolvente.

**Array methods**: Funciones que operan sobre arrays sin bucles explícitos: `map`, `filter`, `reduce`, `find`, etc.

## C

**Closure**: Función que recuerda variables del entorno léxico donde fue creada, incluso cuando se ejecuta en otro lugar.

**Call stack**: Pila donde se apilan las funciones activas. El motor ejecuta desde la cima.

**Callback**: Función pasada como argumento a otra función para ser ejecutada después.

**Componente Ionic**: Elemento UI reutilizable de Ionic (`ion-button`, `ion-card`, `ion-modal`, etc).

## D

**Destructuring**: Extraer valores de objetos y arrays en variables individuales con sintaxis concisa.

**Demo interactiva**: Código ejecutable en el navegador que puedes modificar en tiempo real.

## E

**Event loop**: Mecanismo del motor de JavaScript que coordina la ejecución de código, callbacks y promesas.

**Export/Import**: Palabras clave de módulos ES para compartir código entre archivos.

## F

**Factory**: Patrón que crea objetos sin exponer su lógica de construcción.

**Fetch API**: API nativa del navegador para realizar peticiones HTTP.

## G

**Generator**: Función que puede pausar y reanudar su ejecución con `yield`.

**Glosario**: Este documento.

## H

**Hoisting**: Comportamiento donde las declaraciones `var` y funciones se elevan al inicio del scope.

## I

**IIFE**: Immediately Invoked Function Expression. Función que se ejecuta inmediatamente: `(function() { })()`.

**Ionic**: Framework para construir aplicaciones móviles con HTML, CSS, JavaScript.

## L

**Lazy loading**: Cargar recursos solo cuando se necesitan, no al inicio.

## M

**Map**: Estructura de datos que almacena pares clave-valor.

**Mixin**: Patrón que añade funcionalidad a una clase sin herencia tradicional.

**Módulo**: Archivo con código autocontenido que exporta funciones/valores para otros módulos.

## O

**Observer**: Patrón que notifica a múltiples observadores cuando un objeto cambia.

**Optional chaining**: Operador `?.` que accede de forma segura a propiedades anidadas.

## P

**Promise**: Objeto que representa una operación asíncrona con tres estados: pending, fulfilled, rejected.

**Prototype**: Objeto del que heredan propiedades otras instancias en JavaScript.

**Pull-to-refresh**: Gesto de arrastrar hacia abajo en una lista para recargar contenido.

## R

**Reducer**: Función que toma un acumulador y un elemento para devolver un resultado: usada con `reduce()`.

**REST API**: Interfaz de servidor para obtener/enviar datos usando HTTP.

**Router**: Sistema que mapea URLs a vistas en una aplicación de página única (SPA).

## S

**Scope**: Contexto visible de variables. Puede ser global, local, o de bloque.

**Set**: Estructura de datos que almacena valores únicos.

**Singleton**: Patrón que garantiza una única instancia de una clase.

**Spread operator**: `...` que expande arrays u objetos.

## T

**TDZ (Temporal Dead Zone)**: Zona en la que `let` y `const` existen pero no se pueden usar (antes de su inicialización).

**This**: Palabra clave cuyo valor depende de cómo se llama la función.

**Toast**: Notificación temporal no bloqueante.

## V

**Vanilla JS**: JavaScript puro sin frameworks.

## Z

**Zona muerta temporal**: Ver TDZ.
