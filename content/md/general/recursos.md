## Comandos útiles

```bash
# Crear proyecto Node.js
npm init -y

# Instalar paquete
npm install nombre-paquete

# Ver versión de Node
node --version

# Ejecutar archivo JavaScript
node archivo.js

# Instalar Ionic CLI (opcional)
npm install -g @ionic/cli
```

## Tips de productividad

- Usa snippets para código repetitivo
- Aprende atajos de teclado en tu editor
- Organiza tus demos en carpetas
- Versionea tu código con Git
- Practica el code review de compañeros
