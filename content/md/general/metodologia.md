# Metodología del curso

Este documento describe cómo trabajar efectivamente con el contenido interactivo y demos.

## Cómo aprender con demos interactivas

### 1. Lectura
Lee el concepto teórico en la documentación.

### 2. Experimentación
Ejecuta los ejemplos en el navegador y modifica el código.

### 3. Prueba y error
Cambia valores, añade `console.log()`, rompe el código y aprende.

### 4. Consolidación
Implementa un mini-proyecto o ejercicio sin mirar el código.

## Flujo recomendado de uso

```
Inicio → Selecciona tema (JS o Ionic)
  ↓
Lee la descripción breve
  ↓
Abre la documentación en "Documentación"
  ↓
Vuelve a la demo interactiva
  ↓
Ejecuta el código
  ↓
Modifica y experimenta
  ↓
Implementa tu propio ejercicio
```

## Navegación en la app

- `#/home`: Inicio
- `#/js`: Catálogo JavaScript
- `#/js/:id`: Demo individual (ej: `#/js/fetch-api`)
- `#/ionic`: Catálogo Ionic
- `#/ionic/:id`: Demo individual
- `#/docs`: Documentación

## Uso de DevTools

Abre la consola del navegador (F12) para ver:
- `console.log()` de los ejemplos
- Errores y advertencias
- Resultados de operaciones asincrónicas

## Prácticas recomendadas

### ✅ Bien hecho
- Ejecutar el código primero
- Modificar pequeños detalles
- Escribir tu propio código después
- Usar `console.log()` para entender el flujo

### ❌ No recomendado
- Leer solo sin probar
- Copiar el código sin entender
- Saltarse la documentación
- Intentar todo sin estructura

## Ritmo de aprendizaje

- **Rápido** (3-4 horas por tema): solo demos y ejemplos
- **Normal** (6-8 horas por tema): docs + demos + ejercicios
- **Profundo** (10-15 horas por tema): todo + proyectos + investigación externa

No hay prisa. Entiende cada concepto antes de pasar al siguiente.
