# Guía del alumno

Bienvenido al curso de JavaScript avanzado e Ionic. Esta guía te ayudará a aprovechar al máximo el contenido disponible.

## Estructura del curso

El curso está organizado en tres secciones principales:

### 1. Inicio
Acceso rápido a la información del proyecto y motivación del curso.

### 2. JavaScript avanzado
Profundiza en conceptos clave del lenguaje:
- **Fundamentos**: closures, scope, prototipos, this, hoisting
- **Funciones**: arrow functions, orden superior, currying, generators
- **Asincronía**: event loop, promises, async/await, fetch API
- **Datos**: destructuring, spread, arrays, Map/Set, optional chaining
- **OOP**: clases, privados, mixins, herencia
- **Módulos**: ES modules, import dinámico, patrones
- **Patrones**: singleton, observer, factory

### 3. Ionic
Aprende a construir aplicaciones móviles con componentes Ionic:
- **Estructura**: ion-app, ion-page, layout base
- **Botones**: acciones, FAB, back-button
- **Formularios**: inputs, selects, validación
- **Layout**: listas, cards, grid, accordeón
- **Interacción**: scroll, refresh, reordenar
- **Feedback**: alerts, toasts, modals, overlays
- **Navegación**: router, tabs, menús

## Flujo recomendado

**Semana 1-2**: Fundamentos de JavaScript
- Cierra los conceptos débiles en JS básico
- Practica closures y scope

**Semana 3-4**: JavaScript avanzado
- Estudia asincronía (promises, async/await)
- Implementa casos reales con fetch API

**Semana 5-6**: Patrones y módulos
- Entiende OOP y clases
- Experimenta con patrones de diseño

**Semana 7-8**: Ionic
- Aprende componentes interactivos
- Construye una app sencilla

**Semana 9-10**: Proyecto final
- Combina JS + Ionic
- Demuestra tu aprendizaje

## Cómo usar esta app

- **Demos interactivas**: prueba el código en vivo.
- **Código de referencia**: copia y experimenta.
- **Documentación**: lee los conceptos antes de codificar.
- **Navegación hash**: `#/js`, `#/ionic`, `#/docs` para moverte entre secciones.

## Requisitos previos

- JavaScript básico (variables, funciones, objetos)
- HTML y CSS fundamentales
- Node.js instalado (opcional, pero recomendado)
- Editor de código (VS Code recomendado)

## Objetivos del curso

Al finalizar, serás capaz de:

- ✅ Dominar JavaScript moderno y asincronía
- ✅ Crear aplicaciones móviles con Ionic
- ✅ Aplicar patrones de diseño en tu código
- ✅ Estruturar proyectos escalables
- ✅ Integrar APIs externas en aplicaciones reales
