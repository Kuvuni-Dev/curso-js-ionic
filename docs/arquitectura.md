# Arquitectura propuesta

## 1) App shell
- Entrada unica de la app
- Router por vistas (sin framework)
- Navegacion principal

## 2) Modulo JS
- Ejemplos y demos de JavaScript avanzado
- Utilidades reutilizables

## 3) Modulo Ionic
- Catalogo de componentes de Ionic
- Ejemplos basicos y practicos

## 4) Modulo Contenidos
- Lector de archivos Markdown
- Indice y renderizado de contenidos

## 5) Plataforma
- Build web
- Empaquetado Android con Capacitor

## Desarrollo local
- Ionic cargado por CDN en index.html
- Ejecucion directa con Live Server (sin Vite)
